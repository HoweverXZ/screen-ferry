# 0009 每台设备单独设置

状态：已采纳

## 背景

Mac 开着“自然滚动”时，捕获到的滚动已经按自然方向反过来了，原样发到 Windows 上也按自然方向滚，
不少人希望 Windows 那边和普通鼠标一样。“把 Command 当作对方的 Ctrl”是一个全局开关，
连着几台设备时没法一台互换、一台原样；也没有办法换掉某个键、调光标在对方屏幕上的速度。
连着的设备多了，还需要能给它们起个好认的名字。

## 决定

### 设置在哪里、谁来生效

- 每台已配对的设备一份设置，存在本机 `config.toml` 的 `[[devices]]` 里，按证书指纹区分；
  没有单独设置过的设备用缺省值。配置升到 `schema_version = 4`。
- 键鼠方面的设置（按键、滚动、光标速度、防误切）**只在本机控制它时生效**，由控制的一方（服务端）在发出之前处理。
  这和原来的 Command/Ctrl 互换一致；两边都处理的话，两边各打开一次“滚动反向”就互相抵消了。
- 剪贴板、拖文件两项两边都生效：任何一方对另一方关掉，就不同步、不能拖过去。
  剪贴板要在握手时协商，改了这一项会重新连接。
- 被控制的一方在它那边的设置页上看得到这些项，标明“本机控制它时生效”，并可以请对方打开设置界面、
  直接翻到自己的设置页（见下面的协议）。用户的键鼠本来就在两台之间来回，把光标移过去就能改。

### 各项设置

- **名字**：只在本机显示的名字（设备列表、托盘、日志、拖放胶囊）。改本机自己的名字仍是 `name`，对方看到的就是它。
- **光标速度**：按 DPI 设。本机鼠标的 DPI 是全局设置 `mouse_dpi`（缺省 1600）；每台设备的 `pointer_dpi`
  表示“光标在它上面时，就像接着一个这么多 DPI 的鼠标”，0 表示和本机一样。光标在对方屏幕上的位移乘以
  `pointer_dpi / mouse_dpi`，余数按分母累积，精确到 1 DPI。软件读不到鼠标硬件的 DPI，所以以用户填的为准。
- **滚动**：垂直、水平各自可以反向（缺省都不反向）；速度分慢、标准、快（0.5、1、2 倍）。
  设置界面在本机开着“自然滚动”、对方不是 Mac 时提示可以打开垂直反向。
- **修饰键**：方案分“本机习惯”（两台一台以 Command 为主、一台不是时互换 Command 与 Ctrl，即原来的缺省行为）、
  “原样”、“自定义”（⌘/Windows 键、Ctrl、⌥/Alt、Caps Lock 各自变成 Ctrl、Shift、Alt、⌘/Windows 键、Caps Lock 或不发送，
  左右分别对应）。版本 3 里关掉了互换的，迁移时给每台已配对的设备写上“原样”。
- **其他按键映射**：把一个键换成另一个键，或者不发送。按物理键（USB HID 用法码）记录，设置界面录键时直接取
  键盘事件的物理键。
- **文本编辑快捷键**：两台不是同一种键盘时可以按本机的习惯转换：本机是 Mac 时 ⌘← ⌘→ 到行首行尾、⌥← ⌥→ 按词移动、
  ⌘⌫ 删到行首；本机是 Windows 时 Home、End、Ctrl+← 等转成 Mac 上对应的按法。转换时先在对方那边松开触发它的修饰键，
  松开时再按回来，不会卡键。缺省关着。
- **防止误切**：光标在朝向它的边上停够这么久（0、0.2、0.5 秒）才切过去。
- 这些逻辑都是纯逻辑，放在 `ferry-core`（`KeyMapper`、`WheelScale`、`EdgeSwitch` 的速度与停留），在任何系统上都能测。

### 协议

- 新增能力位 5 `REMOTE_SETTINGS` 和输入连接上的空消息 `OpenSettings`（0x0105）：被控制的一方请控制的一方打开设置界面。
  只在双方都声明了这一位时发送；旧版对方不认识这条消息，所以必须先协商。
- 本机通信升到版本 2：去掉 `settings.swap_cmd_ctrl`，新增 `settings.mouse_dpi`、`settings.devices`、`set_device`、
  `open_peer_settings`、`show_device`，以及 `peers[].alias`、`peers[].platform`、`local.natural_scrolling`。

## 不做

- 被控制的一方直接改对方的设置（经连接同步两边的设置）。需要处理两边同时修改、离线时修改，
  现在用“在对方上打开”就够了。
- 按鼠标加速度曲线换算。只做线性的倍数。
