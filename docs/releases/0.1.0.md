# ScreenFerry 0.1.0

## 简体中文

### 新增

- 一套键盘鼠标控制多台电脑：光标推出屏幕边缘就切到另一台，Mac、Windows 任意搭配
- 任意一台都能当控制端，一台可以控制多台，按布局摆在上下左右
- 剪贴板同步文字、带格式的文字和图片；文件拖到屏幕边缘就发过去，断线后接着传
- 每台设备单独设置光标速度、滚动方向、修饰键和按键映射
- 第一次连接核对 6 位配对码，之后只认对方的证书，连接全程加密
- 局域网里自动找到对方；找不到时可以按地址连接，或从控制端邀请
- 自动检查更新，在后台下载好，点“重启并更新”就装好
- 简体中文和英文界面；Mac 安装盘和 Windows 安装程序

## English

### New

- One keyboard and mouse for several computers: push the cursor past a screen edge to move to the next one, with Mac and Windows in any mix
- Any computer can be the controller, and one can control several, arranged left, right, above or below
- Clipboard sync for text, rich text and images; drag files to a screen edge to send them, and transfers resume after a dropped connection
- Per-device settings for pointer speed, scroll direction, modifier keys and key mapping
- The first connection is confirmed with a 6-digit pairing code; after that only the paired certificate is trusted, and everything is encrypted
- Finds the other computer on the local network automatically; when it can’t, connect by address or send an invite from the controller
- Checks for updates automatically, downloads them in the background, and installs when you click “Restart to Update”
- Simplified Chinese and English interface; a Mac installer disk and a Windows installer
