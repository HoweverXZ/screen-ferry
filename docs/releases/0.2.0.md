# ScreenFerry 0.2.0

## 简体中文

### 改进

- 剪贴板单项大小上限从 64 MB 提到 1 GB，复制大图、长文档不用再分几段（缺省仍是 32 MB，在设置里调整）

### 修复

- 修好被控制的那台电脑上偶尔看不到光标、只能凭感觉找位置的问题

## English

### Improved

- Clipboard items can now be up to 1 GB instead of 64 MB, so large images and long documents can be copied in one go (the default is still 32 MB; change it in Settings)

### Fixed

- Fixed the cursor occasionally disappearing on the computer being controlled, leaving no way to see where the pointer was
