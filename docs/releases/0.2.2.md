# ScreenFerry 0.2.2

## 简体中文

### 修复

- 修好“被控端把文件拖到屏幕边缘时只有一个禁止光标、文件发不出去”的问题：ScreenFerry 以管理员权限运行时，Windows 不允许普通权限的资源管理器把文件拖进来。现在安装完成后会以普通权限启动。

## English

### Fixed

- Fixed dragging files to the screen edge doing nothing but showing a "no entry" cursor when ScreenFerry was running as administrator: Windows blocks drags from Explorer into elevated windows. ScreenFerry is now started as a normal user after installing.
